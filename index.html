    Processing steps

    1. Drop a file

      The file is read from disk with the File API. No upload request is made.

    2. Read the report

      Metadata fields are listed before removal. The original file is not modified.

    3. Remove and download

      Metadata blocks are removed at the container level. Image data is copied byte for byte.

    4. Star the repo
